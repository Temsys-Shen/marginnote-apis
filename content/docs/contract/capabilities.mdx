## 枚举

- `presets`: `book-breakdown`、`source-structure`、`exam-general`、`dictionary`
- `anchorModes`: `page_text`、`block`
- `bundleSubmit.excerptModes`: `child`、`link`（`supportsWithBlank: true`）
- `noteCopy`: `modes: [reference, clone]`，`scope: selected_roots_and_all_mind_map_descendants`，`target: existing_parent_card`，`maxSourceRoots: 50`
- `noteHashtags`: `operations: [add, remove, replace]`，`storedValue: one_complete_leaf_path`，`hierarchySeparator: /`，`maxNoteIds: 200`，`maxHashtags: 100`，`removeDefault: exact_full_path`，`recursiveRemoveFlag: includeDescendants`，`writeRoute: /notes/hashtags`，误用码 `HASHTAG_ROUTE_REQUIRED`
- `noteMetadata`: `maxNoteIds: 200`，`colorIndex: 0..15`，`fillIndex: [-1, 0, 1, 2]`（语义见色板），`palette.route: /study-sets/{id}/note-palette`
- `reviewDeckCards`: `questionModes: [automatic, custom_text, content_part]`，`customTextField: question`，`contentSelectorField: questionContentId`（源为 `batch-get parts[].contentId`，二者互斥），`route: /decks/{id}/cards`
- `imageOcclusions`: `coordinateSpace: normalized_top_left`，`operations: [add, replace]`，`maxMasks: 200`，`nativeStorage: highlight_pic.maskRects`，`requiresDryRun: true`，并发守卫 `expectedSourceFingerprint` + `expectedMaskFingerprint`，不建复习卡、已有卡不自动改
- `documentExport`: `format: pdf`，`route: /documents/{id}/export`，`selectorInput: selectedPageNos`（真实页，省略=全书），`includeRelatedBlankPages.default: true`（隐式带上，不计数），`requiresConfirm: false`
- `mindMapPrint`: `schema: mn.mindMapPrintPlan.v0`，`modes: [keepStructure, classic, cardFlow]`，`densityValue: {min: 0, max: 1, classicCompatibleAt: 0.995}`，`previewRoute` / `exportRoute`，`requiresMax: false`
- `legacySync`: 双通道独立完成；`lanes: [cloudkit, documents]`；`inventoryObserveOnly: true`，`inventoryAuthoritative: false`，最终一致；`recheck` 不直改内容但可能应用远端pending；`verifyHash` 默认关、贵、外部 Provider 不重开
- `guide`: `version: 0.49`，`route: /guide`，`usesExistingBearer: true`，`rotatesToken: false`，`installRequired: false`
