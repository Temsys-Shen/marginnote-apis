# 运行时能力

`GET /capabilities` 返回实例实际注册的路由与能力元数据。静态文档与运行时冲突时用运行时返回。

## 返回字段

- `bridgeApiVersion`，如 `0.39`
- `routeCount`
- `routes`，`{method, path}` 数组
- `presets`，如 `book-breakdown`、`source-structure`、`exam-general`、`dictionary`
- `anchorModes`，如 `page_text`、`block`
- `apiFingerprint`。比对通过后再用静态 OpenAPI

## 请求

```bash
TOKEN=$(cat ~/.config/mn-bridge/token)
curl -s http://127.0.0.1:42340/bridge/v1/capabilities -H "Authorization: Bearer $TOKEN"
```

路由见侧边栏「交互式 API」分组，机器可读定义见 [OpenAPI 说明](/docs/contract/openapi)。
