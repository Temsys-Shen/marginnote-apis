# OpenAPI 说明

机器可读定义在仓库根 `openapi/openapi.yaml`，OpenAPI 3.1，v0.39-draft。

- 由仓库 bot 从 MarginNote 源代码生成，是唯一数据源，构建期由 `lib/openapi.ts` 直读解析。
- 静态文档与运行时冲突时用运行时，含 `apiFingerprint` 比对。
- 部分路由只在 iOS 与 iPadOS 跨设备场景注册，见 spec 内 `x-platforms`。Mac 同机看运行时清单。

## 本站渲染方式

本站用 `fumadocs-openapi` 把它变成虚拟页面，无需落盘 MDX：

- `lib/openapi.ts` 用 `createOpenAPI` 加构建期直读解析的 `openapi.yaml` 加载
- `lib/source.ts` 用 `openapi.staticSource({ groupBy: 'tag' })` 按 Tag 生成分组页面，挂到侧边栏「交互式 API」分组
- `components/api-page.tsx` 用 `createOpenAPIPage()` 渲染参数、请求体、响应 Schema 与多语言代码示例。Playground 已关闭

## 在 Yaak 里调试

<YaakButton />

<Callout type="warn">
spec 的 servers 只有 `/bridge/v1`，没有 host。导入后在 Yaak 里填写 base，如 `http://127.0.0.1:{port}/bridge/v1`，再填 Bearer token。
浏览器 fetch 自带 Origin 头，Bridge 直接返回 403。调 Bridge 的请求不带 Origin。
</Callout>

## 重新生成

运行时升级后直接更新 `openapi/openapi.yaml`，然后重构建本站，`pnpm build`，无需中间转换步骤。
