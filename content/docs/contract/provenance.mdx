## 版本

构建快照：Bridge API `0.39-draft`，定义见 `openapi/openapi.yaml`。

本站是构建时刻的静态快照。连上实例后，路由清单与 `apiFingerprint` 看运行时 `GET /capabilities`。

## 来源

1. MarginNote 源代码经仓库 bot 生成 `openapi/openapi.yaml`，OpenAPI 3.1
2. `node scripts/yaml-to-json.mjs` 转出 `openapi/openapi.json`，构建时静态 import
3. 运行时核对：`GET /status` 探活，无需鉴权。`GET /capabilities` 带 token 核对清单与指纹

## 保密

- 安装码为一次性凭证，用后即废。安装码、token、原始安装响应不提交到公开仓库，不写进 PR、commit message、issue。
- 本站示例用 `$TOKEN` 占位，不含真实凭证。
- 轮换方式：重新执行一次「Copy Agent Setup Command」，旧 token 失效。

## 更新流程

1. 重拉 `GET /status`，比对版本与 `apiFingerprint`
2. 不一致时带现有 token 重拉 `GET /capabilities`，只读刷新
3. `node scripts/yaml-to-json.mjs` 重生成 `openapi/openapi.json`
4. 按 `routeCount` 变化核对指南，`pnpm build` 验证
