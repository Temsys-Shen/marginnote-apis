## 来源链（可复核，不含敏感信息）

1. 运行时状态：`GET /status`（免鉴权 + 带鉴权各一次，确认 `authorized:true`）
2. 运行时能力：`GET /capabilities`（72 路由 + 机器可读附录：`presets/anchorModes/accessPolicy` 等）
3. 运行时规程：`GET /guide`（与已安装 Skill 的 `guideVersion/guideHash` 比对，不一致则以返回为准）
4. 本地原始响应存档于 `raw/`（不提交到公开仓库，仅用于本地生成 OpenAPI 与核对指纹）

## 保密

- 安装码为一次性凭证，用后即废。**不要把安装码、token、原始安装响应提交到公开仓库，也不要写进 PR、commit message、issue。**
- 本站所有示例用 `$TOKEN` / `mnb0.…` 占位，不含真实凭证。
- 轮换：重跑一次新的「Copy Agent Setup Command」即换 token，旧 token 失效。

## 更新流程

1. 重拉 `GET /status`，比对 `guideVersion`/`guideHash`/`apiFingerprint`
2. 不一致 → 带现有 token 重拉 `GET /guide` + `GET /capabilities`（只读刷新，不调安装接口、不轮换 token、不覆写磁盘 Skill 文件）
3. `npm run openapi:build` 重生成 `openapi/openapi.yaml`
4. 按 `routeCount` 差补参考页，`npm run build` 验证
