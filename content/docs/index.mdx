# MarginNote Local Bridge HTTP API

本地 Bridge 的 HTTP 接口文档。

- Base URL 为 `http://127.0.0.1:{port}/bridge/v1`。端口每次现查，默认从 42340 起扫 20 个。
- 公开端点为 `GET /`、`GET /status`、`GET /install`、`POST /pair`。其余请求在 `Authorization` 头携带 Bearer token。
- 请求不带 Origin 头。携带 Origin 头的请求会被拒绝。
- 运行时返回的 `GET /capabilities` 清单与此处的静态文档不一致时，用运行时的。

## 连通性检查

```bash
curl -s http://127.0.0.1:42340/bridge/v1/status

TOKEN=$(cat ~/.config/mn-bridge/token)
curl -s http://127.0.0.1:42340/bridge/v1/status -H "Authorization: Bearer $TOKEN"
curl -s http://127.0.0.1:42340/bridge/v1/capabilities -H "Authorization: Bearer $TOKEN" | head -c 500
```

200 表示 Bridge 正常。带 token 的 status 返回 `authorized:true` 表示令牌有效。

令牌获取方式：MarginNote 设置 → Lab →「Copy Agent Setup Command」，粘进终端执行。安装码 10 分钟有效，单次使用。跨设备走局域网配对，见指南。
