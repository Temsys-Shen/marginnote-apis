## 文档归属

### GET /study-sets/\{id\}/documents（免 Max）

列该集文档（含 `sourceState` normal/missing_file、主文档）。

### POST /study-sets/\{id\}/documents（需 Max + confirm）

```bash
curl -s -X POST "$BASE/study-sets/{topicid}/documents" -H "$AUTH" \
  -H 'Content-Type: application/json' -d '{"bookmd5":"…","confirm":true}'
```

文档须已在库。首次加成主文档（`becameMainDocument:true`），再加为 `addedToBooklist`；重复加幂等（`alreadyPresent:true`）。
空集完整链路：建集（验 `isStudySet`）→ 加文档（验 `becameMainDocument`）→ outline → prepare → submit。

### POST /study-sets/\{id\}/documents/\{docId\}/delete（需 Max + confirm）

App「从学习集中移除」：文档留库，该书有锚卡片失回源（`startpage` 清空、`bookmd5` 改指主文档）。

- 先不带 confirm 打一次，看 `details.notesLosingSource`（失回源卡数），告知后再 confirm
- 主文档可移除（`details.newMainDocumentAfter` 预告上位者）；移除最后一个退回占位符
- 自动打快照（`preRemoveSnapshotId`，存上下文并告知；`warnings` 快照失败则无撤销，须明说）
- `removed:false`/仍在列表 = 未生效，勿报成功

### POST /study-sets/\{id\}/open（免 Max，无 confirm）

```bash
curl -s -X POST "$BASE/study-sets/{topicid}/open" -H "$AUTH" \
  -H 'Content-Type: application/json' -d '{"bookmd5":"…"}'
```

不给 `bookmd5` 即主文档。硬条件：文档本机有文件（挑 `sourceState:normal`，否则 422）。可临时打开非本集文档（`tempOpen:true`，如实告知非「已加入」）。异步，事后 `/context` 对账。会抢屏，仅用户要求时用。

## 结构

### GET /study-sets/\{id\}/tree（免 Max）

扁平 `nodes[{noteid,parent,depth,childCount,…}]`，父子靠 `parent` 拼（非嵌套 `children`）。

- `subMapId` 为归属标签（住在哪张子脑图里，非拥有）；`depth>0` 子脑图可嵌套
- `noteCount`（库记录，摘录亦算）与 tree 节点数口径不同，对不上正常
- 标题超 64 截断，完整走 batch-get
- `?root={子脑图根 noteid}` 读单张子脑图

### GET /study-sets/\{id\}/sub-maps（免 Max）

`[{noteid(根卡),title,cardCount,parentPath,depth}]`，顺序同 App。

### GET /study-sets/\{id\}/notebooks（免 Max）

该集引用了哪些文档笔记本。

## 快照与删除

### GET /study-sets/\{id\}/snapshots（免 Max）／POST /study-sets/\{id\}/snapshots（需 Max）

```bash
curl -s -X POST "$BASE/study-sets/$SS/snapshots" -H "$AUTH" \
  -H 'Content-Type: application/json' -d '{"description":"批量整理前"}'
```

description 不加 `Agent:` 前缀。无变化复用既有版本点（0.18+ 回 `created:false` + `warnings`；更旧无此字段时回读列表核条数）。批量写前必打。

回退 `POST /snapshots/{id}/restore` 见 Snapshots 章。

### POST /study-sets/\{id\}/delete（需 Max + confirm，最重）

```bash
curl -s -X POST "$BASE/study-sets/$SS/delete" -H "$AUTH" \
  -H 'Content-Type: application/json' \
  -d '{"expectedTitle":"<库中现值>","confirm":true}'
```

- `expectedTitle` 必填且须完全一致（否则 409 `TITLE_MISMATCH` + `actualTitle`）；调用前读出标题卡数展示获同意
- 默认 `keepHighlights:true`（卡隐藏、清 mindlinks、划线保留）+ `keepSnapshotHistory:true`（自动打快照）；彻底清才显式 false（不可恢复）
- 语义为不再满足学习集判据（`removedFromLibrary` 回读自证）
- `preDeleteSnapshotId` 为后悔药（可能复用既有快照，描述未必是删除前备份，内容一致即有效）；删完告知
- 卡组删除走同一端点（`keepHighlights:false` 才真干净，默认仍在 `GET /decks`）

## 标签与色板

### GET /study-sets/\{id\}/hashtags（免 Max）

实际存储 `hashtags[]` + 派生扁平 `nodes[]` + 嵌套 `tree[]`。`directCardCount` 仅直存；`cardCount` 含后代；`derived:true` 为推导层。

### GET /study-sets/\{id\}/note-palette（免 Max）

16 项 `{colorIndex(0-based),baseColor,displayColor(hex+rgba)}`。`source: default|study-set`。拆书 `[style:]` 与 `notes/metadata` 选色前必读，禁硬编码颜色名。`fillIndex` 语义（与 `/capabilities.fillIndexSemantics` 同源）：`-1` legacy_adaptive（文字填+线，区域仅轮廓）／`0` fill_and_stroke／`1` fill_only／`2` stroke_only（文字仅下划线，区域仅轮廓；「不填色」选 2）。

## 脑图打印（0.49+，免 Max，无 confirm）

### POST /study-sets/\{id\}/mindmap-print/preview

```bash
curl -s -X POST "$BASE/study-sets/$SS/mindmap-print/preview" -H "$AUTH" \
  -H 'Content-Type: application/json' \
  -d '{"mode":"keepStructure","densityValue":0.85,"rootNoteId":"可选分支根"}'
```

规划入口，不落文件。`keepStructure` 默认逐级（保留局部形态/图片/手写/页码跳转；过大总览降 `visibleDepth`，`pages[].kind` 区分 branchOverview/mergedSiblingBranches/singleCard；过密用 `sliceIndex/sliceCount` + `visibleNoteIds` 拆页）；`classic`/`densityValue=1` 旧兼容；`cardFlow` 密集卡片流。返回 `schema: mn.mindMapPrintPlan.v0`（`pageCountEstimate/pages[]/exportOptions/planFingerprint` + 警告）。CLI 不自算分页。

### POST /study-sets/\{id\}/mindmap-print/export

推荐只传 `{"plan":<preview 保存的计划>,"fileName":"可选.pdf"}`；复用 `pages[]/visibleDepth/visibleNoteIds`，执行阶段不重算。输出到外部导出根 `MindMapExports`（未配置落 App 容器，需完全磁盘访问）。与文档导出共享 `429 EXPORT_BUSY`。CLI 推荐 `--save-plan` 预览 → 用户确认 → `--from-plan --execute`。
