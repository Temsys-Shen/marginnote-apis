Base：`http://127.0.0.1:{port}/bridge/v1`。除 `GET /status` 外一律 Bearer；不带 Origin。参数、Schema、Try-it 见各端点交互页（左侧 System / Setup 分组）。

## GET /status（免鉴权）

> [交互式](/docs/system/get-status)

- 判活只看它；带 token 时 `authorized:true` 才正常。`guide.route` 为 `/guide`；`refreshPolicy` 为版本/hash 不一致即刷新；`rotatesToken:false`。

## GET /capabilities（Bearer）

> [交互式](/docs/system/get-capabilities)

- 机器可读附录（`accessPolicy/presets/anchorModes/...`）见 [运行时能力](/docs/contract/capabilities)。
- `requiresMax:false` 仅表示有效 token 下免 Max，不是免 token。

## GET /guide（Bearer）

> [交互式](/docs/system/get-guide)

- 运行时规程 Markdown。开场对账：版本/hash 不一致即以它为准，只读刷新。

## GET /context（Bearer，只读）

> [交互式](/docs/system/get-context)

- 用户说「这张卡」「这页」时先打它，别让用户口述 id。
- `currentPage.page` 为 PDF 页序；blank 页已换算真实页，虚拟页号绝不传 PDF 接口；`mappingAvailable:false` 则问用户。
- `selectedNotes` 空正常；`focusedNote` 为焦点/缩放根 ≠ 选中卡。`studySet.isDeck:true` = 复习卡组（勿往里拆书）。`available:false` 按 `reason` 回退，勿重试。

## GET /install?code=（一次性）

> [交互式](/docs/setup/get-install)

- code 10 分钟有效、只能用一次。成功写 token（600）+ 装 Skill + 提示 MCP；失败回过期提示脚本（403）。

## POST /install/code（Bearer，安装辅助，无 confirm 门）

> [交互式](/docs/setup/post-install-code) · [危险纪律](/docs/reference/dangerous-endpoints)

- 无 confirm 轮换保护。刷新规程只读 `GET /guide`（不调安装接口、不轮换 token、不覆写磁盘文件）。

## 跨设备配对 POST /pair（指南记录，能力清单快照无此条）

- 运行时指南（`GET /guide` §0）记录的配对端点：6 位码 + `deviceName` 换 token；码 5 分钟有效、一次、错三次作废；失败一律 `PAIRING_FAILED`。
- 当前 `capabilities` 快照的 72 路由未含它，调用前以运行时 `GET /capabilities` + `GET /guide` 为准（清单有而规程没写的可用；规程有而清单没有的别调）。

## POST /mcp（Bearer）

> [交互式](/docs/setup/post-mcp)

- `GET /mcp` 未实现（501）属预期，以 POST 为准。工具仅 `mn_guide` + `mn_call`；能力表达仍在规程里，MCP 只建连。图片经 `mn_call` 以 MCP `image` 内容返回。
